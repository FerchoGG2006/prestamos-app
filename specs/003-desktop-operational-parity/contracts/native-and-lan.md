# Native and LAN contracts
Customer actions invoke injected lifecycle/followup/attachment services. All errors remain visible; no financial fallback. Promise fulfillment is explicit bookkeeping only. Recovery is manager-only, into an empty folder, displays validation result before extraction and does not restart or replace current office.
LAN /api/sync/status is read-only connectivity metadata. Base pull/push requires configured X-Office-Sync-Pin; unconfigured server refuses data operations. Manager-issued /enlace/<token>/api/sync/pull|push fixes route and collector independent of query/body. Pairing expires and requires initiating manager still authenticated. Export settings excludes passwords, hashes, credentials and secrets. Legacy fields/states normalize at boundary; invalid financial bundle rolls back.
