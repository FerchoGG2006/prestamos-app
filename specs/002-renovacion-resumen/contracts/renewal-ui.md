# Contrato nativo de renovación

El formulario muestra tasa TOTAL del plazo, capital nuevo, cuotas, modalidad, fecha, saldo anterior y papelería configurada. El resumen de ruta muestra interés, nueva deuda, neto y Base/cartera/Administrativo antes → después.

Consultar no escribe. Aprobar abre confirmación nativa con importes principales. Cancelar no escribe. El comando lleva el resumen esperado; si la nueva lectura no coincide, no se registra y se invita a revisar de nuevo. Errores se muestran dentro del diálogo y deshabilitan aprobación hasta disponer de un cálculo válido. La papelería se identifica como salida de Base operativa.

Datos de alcance: ruta del crédito, no selector de todas las rutas. El libro existente agrupa efectivo y fondos digitales; queda advertido en la auditoría hasta separar esos saldos.
